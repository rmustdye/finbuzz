# FinBuzz ⌁ — search attention vs. market reality

A self-built market research engine. It ingests raw, untouched downloads from
Google Trends and Yahoo Finance, verifies them, runs the statistics honestly,
and publishes the result as a live dashboard.

**Live site:** https://rmustdye.github.io/finbuzz/

## What's in the repo

Everything lives at the root — no subfolders, no upload hassle:

| File | What it is |
|---|---|
| `index.html` | The live dashboard (this is your website) |
| `data.js` | Generated by the pipeline — never edit by hand |
| `.nojekyll` | Tells GitHub "serve plain HTML, don't run Jekyll" |
| `finbuzz_pipeline.py` | The entire engine — auto-detects raw file formats |
| `FinBuzz_Trends_Data.csv` | Raw Google Trends data |
| `FinBuzz_Merged_Data_FINAL.csv` | Original Colab export with prices |
| `analysis_summary.json` | Plain-language stats summary |

## Deploy (one time, ~5 minutes)

1. Create a **public** repo on GitHub named `finbuzz`.
2. Upload all files (drag-and-drop on the repo page).
3. **Settings → Pages → Branch: main → Folder: / (root) → Save.**
4. Wait ~2 minutes. Live at `https://rmustdye.github.io/finbuzz/`.

## Refresh the data

**Step 1 — Google Trends.** https://trends.google.com → search **AI stocks**
→ United States → Custom time range → 2025-11-20 to today (keep under ~9
months) → download the chart → drop `multiTimeline.csv` into the repo as-is.

**Step 2 — Yahoo Finance.** https://finance.yahoo.com → **NVDA** → Historical
Data → same range → Download → drop the CSV into the repo as-is.

**Step 3.** `python finbuzz_pipeline.py` (locally or Google Colab).

**Step 4.** Push. The site updates itself.

## Honesty notes

- Google Trends scores are **relative and re-sampled per request**.
- Correlations use **daily percentage changes**, not raw levels.
- Educational research project. **Not investment advice.**
